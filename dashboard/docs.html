EcoSched Architecture & Technical Guide

A Carbon-Aware Workload Orchestrator and Simulation Framework for Geo-Distributed Heterogeneous Compute Clusters.

Core Purpose: EcoSched addresses the fundamental limitation of contemporary cloud orchestrators (Kubernetes, Slurm) which are 100% carbon-blind. By pairing real-time marginal grid carbon signals ($g\text{CO}_2\text{eq}/\text{kWh}$) with remaining execution slack $S_j(t) = D_j - (t + d_j)$, EcoSched unifies temporal deferral with spatial WAN shifting to cut emissions by up to 34.7% while guaranteeing 100% SLA compliance.

1. System Architecture & Component Design

The system is organized into modular packages under src/:

  • src/core/models.py: Pydantic schemas for tasks, nodes, regions, and lifecycle states.
  • src/core/node.py: Models non-linear SPECpower CPU polynomial curves and low-power standby sleep states ($15\text{W}$).
  • src/core/task.py: Tracks dynamic execution progress, remaining duration, and slack windows.
  • src/core/grid.py: Vectorized NumPy lookup engine for sub-microsecond carbon intensity interpolation and moving-average green valley search.
  • src/core/cluster.py: Geo-distributed topology coordinator modeling inter-datacenter WAN latency and bandwidth matrices.
  • src/simulator/engine.py: Discrete-Event Simulation (DES) execution loop driving cluster state transitions.
  • src/schedulers/: Implements CarbonSlack_Novel, FIFO_Default, Energy_Greedy_Consolidation, and Spatial_Only_Carbon.

2. Mathematical Formulation

A. Non-Linear SPECpower Server Power Model

P_n(t) = P_{standby} * PUE_r                   (if u_n = 0 and g_n = 0)
P_n(t) = [P_{idle} + ΔP(2u - u^1.4) + P_{gpu}] * PUE_r   (if u_n > 0)

B. Dynamic Slack-Window Triage

S_j(t) = Deadline_j - (CurrentTime_t + Duration_j)

if S_j(t) <= 20 min  ➔  SLA-CRITICAL  ➔  Immediate Placement Guaranteed
if S_j(t) >  20 min  ➔  ELASTIC       ➔  Green Valley Delay / WAN Migration

C. Inter-Region WAN Latency Matrix

TransferDelay = RTT(src, dst) + (DataSize_GB * 8) / Bandwidth_Gbps

3. Quickstart & Local Reproduction

# 1. Clone repository
git clone https://github.com/durgesh261/EcoSched.git
cd EcoSched

# 2. Set up Python virtual environment
python -m venv venv
.\venv\Scripts\activate   # Windows
source venv/bin/activate  # Linux / macOS

# 3. Install dependencies
pip install -r requirements.txt
pip install -e .

# 4. Run Pytest unit & integration test suite
pytest -v

# 5. Execute full benchmark suite and generate 300 DPI figures
python scripts/run_experiments.py

4. Docker Reproducibility

# Build Docker container image
docker build -t ecosched:latest .

# Run benchmark suite inside container
docker run --rm -v $(pwd)/output:/app/output ecosched:latest
